# 🧠 About the Project

This project was built while completing the **Unity Essentials Pathway**, Unity’s beginner learning experience for new developers. The goal of the project was to apply the core concepts taught throughout the pathway into a fully playable interactive experience.

Through this project, I gained hands-on experience with:

- Navigating the Unity Editor
- Building and organizing scenes
- Working with GameObjects and components
- Using prefabs and assets
- Writing and editing C# scripts in Visual Studio Code
- Configuring cameras and audio
- Publishing a playable Unity project online

---

# 🎓 About Unity Essentials

The Unity Essentials Pathway is Unity’s official foundational learning pathway designed for beginners with no prior experience. It teaches the core concepts needed to start creating games and interactive real-time experiences in Unity.

The pathway covers topics such as:

- Unity Editor fundamentals
- Scene building
- Cameras
- Audio systems
- GameObjects and prefabs
- Introductory C# scripting
- Publishing projects online

Learn more here:  
https://learn.unity.com/pathway/unity-essentials?version=

# 💻 How to Run Locally

If you want to open the project locally in Unity:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Then:

1. Open **Unity Hub**
2. Click **Add Project**
3. Select the cloned repository folder
4. Open the project in the correct Unity version
5. Press ▶ Play inside the Unity Editor
